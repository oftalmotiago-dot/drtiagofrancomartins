# Canvas editável do carrossel

Cada `*.dc.html` é uma prancheta de 1080 × 1350 px — um slide do carrossel.
`canvas.json` define posição, títulos e notas. `gen.py` gera os dez arquivos
a partir de um único conjunto de estilos, para manter a consistência visual.

As duas fotos de referência (`slitlamp.jpg` e `surgery.jpg`) não são
versionadas aqui — são do acervo pessoal. Elas ficam embutidas no canvas
publicado, de onde podem ser recuperadas se precisar remontar tudo.

Ordem dos slides: Main · Definicao · Sinais · Funcional · SuperiorInferior ·
PeleMusculo · Cirurgia · Recuperacao · Mitos · Fechamento.
